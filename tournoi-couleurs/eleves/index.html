COUPE TYPHON

Les sports

Les sports prévus pour les trois premiers cycles de la Coupe Typhon.
Cycle 1
⚽

Futsal

Premier cycle

Règlements

  • Les murs font partie du jeu : il n’y a aucune sortie sur les côtés.
  • Sortie derrière le but : remise en jeu selon l’équipe qui a touché le ballon en dernier.
  • Pas de contact physique dangereux, de poussée ni de tacle glissé.
  • Les fautes donnent une remise en jeu à l’équipe adverse.
  • Le gardien peut utiliser ses mains dans sa zone.
  • Un but compte lorsque le ballon franchit complètement la ligne de but.
Cycle 2
🥏

Ultimate

Deuxième cycle

Règlements

  • Un point est marqué lorsqu’un joueur attrape le disque dans la zone de but adverse.
  • Il est interdit de courir avec le disque; le joueur doit établir un pied de pivot.
  • Si le disque touche le sol, sort du terrain ou est intercepté, l’autre équipe prend possession.
  • Aucun contact physique volontaire.
  • Le défenseur doit laisser l’espace nécessaire au lanceur.
  • Les joueurs s’auto-arbitrent dans un esprit de respect et d’esprit sportif.
Cycle 3
🏐

Dodgeball

Troisième cycle

Règlements

  • Un joueur touché directement par un ballon lancé par l’adversaire est éliminé.
  • Un ballon qui touche le sol avant de toucher un joueur n’élimine personne.
  • Si un joueur attrape directement un ballon lancé, le lanceur est éliminé.
  • Les joueurs doivent demeurer dans leur zone et respecter les lignes du terrain.
  • Les lancers à la tête sont interdits.
  • L’équipe qui élimine tous les joueurs adverses remporte la manche.
